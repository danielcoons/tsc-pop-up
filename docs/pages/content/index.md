# TSC Pop-Up

This is an **Awesome** LabVIEW toolkit that gives the ability to have customized pop-up dialogs in LabVIEW User Interfaces.

Install the VIP package from [VIPM](https://www.vipm.io/package/tsc_lib_tsc_pop_up/).

The TSC pop-up library lets you create customized pop-up dialogs to give users instructions, warnings, or to get their attention.

## Pop-up families

- **Standard**: image pop-ups with a consistent size and a set of [built-in images](/pop-up/standard-images)
- **PNG**: image pop-ups where you define a custom image to load while running, with control over image placement and the size of the message text box.
- **Plain**: a simple dialog with one, two or three buttons and a defined **Title**.

See the example VIs for usage of a few of the pop-up types.

> ✨ Double-click a pop-up to make it semi-transparent.
