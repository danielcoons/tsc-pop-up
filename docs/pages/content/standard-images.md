# Standard images

Use these names with the **Graphics** input of a standard pop-up.

| | |
| --- | --- |
| ![Information icon](/assets/pop-up/images/info.png) | ![Question icon](/assets/pop-up/images/question.png) |
| **`info`** — General information. | **`question`** — Requests a decision. |
| ![Hourglass icon](/assets/pop-up/images/hourglass.png) | ![Green check mark](/assets/pop-up/images/green%20check.png) |
| **`hourglass`** — Waiting or processing. | **`green check`** — Successful completion. |
| ![Red check mark](/assets/pop-up/images/red%20check.png) | ![Warning icon](/assets/pop-up/images/warning.png) |
| **`red check`** — Unsuccessful completion. | **`warning`** — Warning or caution. |
| ![Connect icon](/assets/pop-up/images/connect.png) | ![Disconnect icon](/assets/pop-up/images/disconnect.png) |
| **`connect`** — Connection action or status. | **`disconnect`** — Disconnection action or status. |
| ![Not allowed icon](/assets/pop-up/images/not%20allowed.png) | ![Tools icon](/assets/pop-up/images/tools.png) |
| **`not allowed`** — Unavailable or prohibited action. | **`tools`** — Configuration or maintenance. |
| ![Over-temperature icon](/assets/pop-up/images/over-temp.png) | ![Low voltage icon](/assets/pop-up/images/voltage-low.png) |
| **`over-temp`** — Over-temperature condition. | **`voltage-low`** — Low-voltage condition. |
 ![Medium voltage icon](/assets/pop-up/images/voltage-mid.png) | ![High voltage icon](/assets/pop-up/images/voltage-high.png) | 
 **`voltage-mid`** — Intermediate-voltage condition.| **`voltage-high`** — High-voltage condition. | 

> **Note:** Use the following images for messages involving classified information. **They do not denote any classified content**.

| | |
| --- | --- |
| ![Classified icon](/assets/pop-up/images/image-classified.png) | ![Secret icon](/assets/pop-up/images/image-secret.png) |
| **`image-classified`** — Classified information. | **`image-secret`** — Secret information. |
