# Standard images

Use these names with the **Graphics** input of a standard pop-up.

| | | |
| --- | --- | --- |
| ![Information icon](/assets/pop-up/images/info.png) | ![Question icon](/assets/pop-up/images/question.png) | ![Hourglass icon](/assets/pop-up/images/hourglass.png) |
| **`info`** — General information. | **`question`** — Requests a decision. | **`hourglass`** — Waiting or processing. |
| ![Green check mark](/assets/pop-up/images/green%20check.png) | ![Red check mark](/assets/pop-up/images/red%20check.png) | ![Warning icon](/assets/pop-up/images/warning.png) |
| **`green check`** — Successful completion. | **`red check`** — Unsuccessful completion. | **`warning`** — Warning or caution. |
| ![Connect icon](/assets/pop-up/images/connect.png) | ![Disconnect icon](/assets/pop-up/images/disconnect.png) | ![Not allowed icon](/assets/pop-up/images/not%20allowed.png) |
| **`connect`** — Connection action or status. | **`disconnect`** — Disconnection action or status. | **`not allowed`** — Unavailable or prohibited action. |
| ![Tools icon](/assets/pop-up/images/tools.png) | ![Over-temperature icon](/assets/pop-up/images/over-temp.png) | ![Classified icon](/assets/pop-up/images/image-classified.png) |
| **`tools`** — Configuration or maintenance. | **`over-temp`** — Over-temperature condition. | **`image-classified`** — Classified information. |
| ![Secret icon](/assets/pop-up/images/image-secret.png) | ![Low voltage icon](/assets/pop-up/images/voltage-low.png) | ![Medium voltage icon](/assets/pop-up/images/voltage-mid.png) |
| **`image-secret`** — Secret information. | **`voltage-low`** — Low-voltage condition. | **`voltage-mid`** — Intermediate-voltage condition. |
| ![High voltage icon](/assets/pop-up/images/voltage-high.png) |  |  |
| **`voltage-high`** — High-voltage condition. |  |  |
