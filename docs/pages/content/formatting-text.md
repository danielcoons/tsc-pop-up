# Formatting text

The message text in a pop-up can be formatted with HTML-style tags.

```html
<b>bold</b>
<i>italic</i>
<strong>strong</strong>
<del>strike</del>
<em>emphasis</em>
<ins>underline</ins>
<font rgb(0, 0, 255)><b>blue</b></font> other text
<font rgb(0, 255, 0)>green</font>
<font rgb(255, 0, 0)>red</font>
```

> Tags can be nested, but the inner tag must be closed **before** the outer tag.
