# Pop-up types

Each pop-up family provides the options below.

| | |
| --- | --- |
| **One button**<br>A dialog box with a single button.<br><br><img src="/assets/pop-up/images/one-button.png" alt="One-button pop-up" width="280"> | **Two button**<br>A dialog with a choice of `Y` or `N`.<br><br><img src="/assets/pop-up/images/two-button.png" alt="Two-button pop-up" width="280"> |
| **Timeout**<br>Displays a message for a defined time.<br><br><img src="/assets/pop-up/images/timeout.png" alt="Timeout pop-up" width="280"> | **Timeout one button**<br>Displays a message until the allotted time runs out or the single button is selected.<br><br><img src="/assets/pop-up/images/timeout-one.png" alt="Timeout one-button pop-up" width="280"> |
| **Timeout two button**<br>Displays a message until the allotted time runs out or a choice of `Y` or `N` is made. `N` is selected by default if time elapses.<br><br><img src="/assets/pop-up/images/timeout-two.png" alt="Timeout two-button pop-up" width="280"> | **Input**<br>Input pop-ups return a DBL, an I32, or a string value.<br><br><img src="/assets/pop-up/images/dbl-input.png" alt="DBL input pop-up" width="280"><br><br><img src="/assets/pop-up/images/i32-input.png" alt="I32 input pop-up" width="280"><br><br><img src="/assets/pop-up/images/str-input.png" alt="String input pop-up" width="280"> |

> Typical key behavior: `Return` triggers the single button or `Y`, and `Esc` triggers `N`.
