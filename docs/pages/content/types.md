# Pop-up types

Each pop-up family provides the options below.

| | |
| --- | --- |
| ![One-button pop-up](/assets/pop-up/images/one-button.png) | ![Two-button pop-up](/assets/pop-up/images/two-button.png) |
| **One button** — A dialog box with a single button. | **Two button** — A dialog with a choice of `Y` or `N`. |
| ![Timeout pop-up](/assets/pop-up/images/timeout.png) | ![Timeout one-button pop-up](/assets/pop-up/images/timeout-one.png) |
| **Timeout** — Displays a message for a defined time. | **Timeout one button** — Displays a message until the allotted time runs out or the single button is selected. |
| ![Timeout two-button pop-up](/assets/pop-up/images/timeout-two.png) | ![DBL input pop-up](/assets/pop-up/images/dbl-input.png) |
| **Timeout two button** — Displays a message until the allotted time runs out or a choice of `Y` or `N` is made. `N` is selected by default if time elapses. | **Input (DBL)** — Returns a DBL value. |
| ![I32 input pop-up](/assets/pop-up/images/i32-input.png) | ![String input pop-up](/assets/pop-up/images/str-input.png) |
| **Input (I32)** — Returns an I32 value. | **Input (string)** — Returns a string value. |

> Typical key behavior: `Return` triggers the single button or `Y`, and `Esc` triggers `N`.
