# Pop-up types

In general, each pop-up library type has these options.

## One button

A dialog box with a single button.

![One button](/assets/pop-up/images/one-button.png)

## Two button

A dialog with a choice of `Y` or `N`.

![Two button](/assets/pop-up/images/two-button.png)

## Timeout

Displays a message for a defined time.

![Timeout](/assets/pop-up/images/timeout.png)

## Timeout one button

Displays a message until the allotted time runs out or the single button is toggled.

![Timeout one button](/assets/pop-up/images/timeout-one.png)

## Timeout two button

Displays a message until the allotted time runs out or a choice of `Y` or `N` is made. `N` is selected by default if time elapses.

![Timeout two button](/assets/pop-up/images/timeout-two.png)

## Input

Input pop-ups return a DBL, an I32 or a string value.

![DBL input](/assets/pop-up/images/dbl-input.png)
![I32 input](/assets/pop-up/images/i32-input.png)
![String input](/assets/pop-up/images/str-input.png)

> Typical key behavior: `Return` triggers the single button or `Y`, and `Esc` triggers `N`.
